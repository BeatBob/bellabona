# Project Brief — Bella&Bona Homepage Case Study

## Context
Freelance technical test for **Bella&Bona** (B2B workplace meal company, Munich). Evaluating for a HubSpot → Next.js + Sanity migration. This test is the **homepage only**.

Competitive bid. Stated evaluation priority: **technical decisions, rendering strategy, and SEO awareness over visual polish.** Architecture and the README matter more than pixel perfection.

## Time Budget
4–6 hours total. Do not over-engineer.

## Strict Stack
- Next.js 14+ **App Router** (not Pages Router)
- TypeScript
- Tailwind CSS
- Sanity v3 (Studio embedded at `/studio`)
- Deploy: Vercel

Ask before adding any dependency outside this stack.

## Deliverables
1. Public GitHub repo
2. Vercel preview URL
3. README per `docs/README_OUTLINE.md`
